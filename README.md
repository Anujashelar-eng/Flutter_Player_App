# Flutter Player App

A Flutter learning project demonstrating Firebase Authentication, Cloud Firestore, SharedPreferences, and Splash Screen navigation.

## Features

- User Signup with Firebase Authentication
- User Login with Firebase Authentication
- Persistent Login using SharedPreferences
- Splash Screen with automatic navigation
- Store and retrieve user data using Cloud Firestore
- Logout functionality

## Tech Stack

- Flutter
- Dart
- Firebase Authentication
- Cloud Firestore
- SharedPreferences

## Getting Started

1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Flutter_Player_App.git
```

2. Navigate to the project

```bash
cd Flutter_Player_App
```

3. Install dependencies

```bash
flutter pub get
```

4. Add your Firebase configuration

- Place `google-services.json` inside `android/app/`
- Configure Firebase for your project

5. Run the app

```bash
flutter run
```
